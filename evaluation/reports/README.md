# Evaluation reports

Detailed run output is excluded from Git. Answer evaluation JSON records contain
configuration fingerprints, dataset versions, actual retrieved evidence, answers,
model-judged scores with reasons and latency. Matching CSV exports contain completed
answers and scores. Token usage and generated SQL are not currently measured.
Credentials and raw API error strings are excluded.

See `docs/evaluation.md` for commands, review steps and interpretation limits.
Final reviewed comparisons and conclusions belong in versioned documentation.
